# 艇読みAI

ボートレースの出走表・直前情報・結果を自動で集め、3連単の「本線」と「人気より強い穴」を出す予想アプリ。

- アプリ: https://nextroad11.github.io/teiyomi/
- データ: `data` ブランチ（日付ごとのJSON）

## しくみ

| 役割 | 担当 | 場所 |
|---|---|---|
| データ取得（5分おき、日本時間7:00〜24:59） | GitHub Actions | `.github/workflows/scrape.yml`, `scraper/` |
| 予想の計算と表示 | ブラウザ | `docs/index.html` |
| 予想の重みの調整 | Claude | `docs/model.json` |

### 取得のタイミング
- その日最初の実行（7時台）: 全場・全レースの出走表
- 締切25分前〜締切3分後: 直前情報（展示タイム・チルト・進入・風・波）
- 締切8分後〜: 3連単の結果と払戻

### 予想エンジン
1. 各艇を点数化（全国勝率・当地勝率・モーター・ボート・平均ST・展示タイム・F持ち）
2. コース別の勝ちやすさと合わせ、3連単120通りの確率を計算
3. 勝率と級別だけで見た「人気の想定」も同じ方法で計算
4. 本線 = AI確率の上位、穴 = AI確率が人気想定を上回る推定20倍以上の買い目

データ出典: BOAT RACE オフィシャルウェブサイト。公式サイトへの負担を抑えるため、取得は1秒に1回までにしています。
