# 艇読みAI

ボートレースの出走表・直前情報・結果を自動で集め、3連単の「本線」と「人気より強い穴」を出す予想アプリ。

- アプリ: https://nextroad11.github.io/teiyomi/
- データ: `data` ブランチ（日付ごとのJSON）

## しくみ

| 役割 | 担当 | 場所 |
|---|---|---|
| データ取得（5分おき、日本時間7:00〜24:59） | GitHub Actions | `.github/workflows/scrape.yml`, `scraper/` |
| 予想の計算と表示 | ブラウザ | `docs/index.html` |
| 予想の重みの調整 | Claude | `docs/model.json` |

### 取得のタイミング
- その日最初の実行（7時台）: 全場・全レースの出走表
- 締切25分前〜締切3分後: 直前情報（展示タイム・チルト・進入・風・波）
- 締切8分後〜: 3連単の結果と払戻

### 予想エンジン
1. 各艇を点数化（全国勝率・当地勝率・モーター・ボート・平均ST・展示タイム・F持ち）
2. コース別の勝ちやすさと合わせ、3連単120通りの確率を計算
3. 勝率と級別だけで見た「人気の想定」も同じ方法で計算
4. 本線 = AI確率の上位、穴 = AI確率が人気想定を上回る推定20倍以上の買い目

データ出典: BOAT RACE オフィシャルウェブサイト。公式サイトへの負担を抑えるため、取得は1秒に1回までにしています。

## B級ウォッチ（試験版・docs/test.html）
- `scraper/bwatch.py` が毎朝（`.github/workflows/bwatch.yml`、日本時間7:23）、各開催の**前日まで**の足スコアを開催全体でまとめて評価し、B級選手をS〜Dにする。当日の展示・結果は使わない。
- 評価のしかた：項目（一周・まわり足・直線・展示）ごとに「タイム＝レース効果＋選手効果」を解いて水面・時間帯の差を除き、場の重みで合計。古い日も同じ重み（傾斜をかけても良くならなかった）。
- S＝開催の上位10%、A＝10〜25%、B＝25〜45%、C＝45〜70%、D＝残り。計測1走は1段階下げ、B2は最高A、足が効きにくい場（江戸川・住之江・三国・蒲郡）は最高B。
- 過去1年のバックテスト（後半の使っていない期間）で、3連対はS 50.6%・A 46.7%・B 42.4%・C 38.6%・D 31.7%。当日の展示を入れたAIに上乗せしても予測が良くなる（改善度+19）。
- 画面では、AIの確率に今節の足（係数0.08）を足し、B級選手を1着・2着に置いた3連単のうち期待値1.2以上だけを推奨。期待値の基準はオッズの記録がたまってから検証する。
- 本番のアプリ（index.html）と通知には、確認を取ってから入れる。
